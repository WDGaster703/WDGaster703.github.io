空洞骑士系列随想

本文最后更新于 2026年6月22日 晚上

2025 年 11 月，器乐部开始排练《空洞骑士组曲》，在大王指挥的倾情推荐（实则是免费赠送）下，由空洞骑士开启了我的类银河恶魔城游戏游玩之路。

Hollow Knight（空洞骑士）

类银界最高的山！空洞骑士作为类银的出圈之作，地图体量和怪物设计均远超类银界诸作，丰富程度量大管饱。

故事发生在圣巢（Hollownest）衰败之后，昔日繁盛的国度已化为一片废墟，小骑士以旁观者的视角，走过圣巢的每一片土地，十字路的衰败与感染后的惊怖，苍绿之径的葱翠郁郁，真菌荒地的生机勃勃，泪水之城的圣洁苍凉与富人区的富丽堂皇，皇家水道的刺耳与伊思玛森林的静谧，水晶山峰的机械轰鸣，安息之地的宁静哀伤，古老盆地的空虚，王国边境的落寞孤寂，雾之峡谷的幽静，王后花园的苍翠繁盛，呼啸悬崖的偏远空旷，深邃巢穴的昏暗阴森，不同区域共同诉说着圣巢王国曾经的辉煌和经历的惨痛。

旅途中，与奎若相识相伴，在前行路上总会有令人安心的身影在前方等候，乌姆一战，奎若如定海神针（在神居打乌姆无比怀念奎若的助战）帮助小骑士战胜敌人，当头上的面具取下，奎若乐天温和的声线一瞬苍老，最终，在蓝湖边，陪伴奎若度过最后一刻，看着这位亦师亦友的前辈离去。作为教师莫诺蒙的学生，奎若见证了圣巢繁荣与衰败，跟着莫诺蒙学习了圣巢诸多学识，然而老师沉眠前给予的面具让奎若忘记了一切并游历世界，直至小骑士到来杀死教师莫诺蒙，奎若被命运感召完成老师的最后任务，在泪城上方的蓝湖旁静候终局，并留下了“我忘记了所有悲剧，所见皆是奇迹”（All tragedy erased. I see only wonders），潸然泪下。奎若的前半生在圣巢的繁盛中度过，向老师莫诺蒙学习诸多学识，在接受老师的托付后，虽然遗忘了过去，但是乐天温和的性格让奎若游历世界时仍然享受世界的万物万事，“我见过这个世界两次，但我的使命可能让我忘记了第一次的感觉。真高兴能再一次见证这美丽的世界”。

在苍绿之径，初次遇见大黄蜂，经过一段绕路，在乌恩之湖的必经之路上一战大黄蜂，击败后第一次与守梦人对话。随后在朝圣者大道、泪城空洞骑士雕像、王国边缘会依次遇到大黄蜂，并在沃姆的遗弃外壳前二战大黄蜂，两战两胜赢得了大黄蜂的认可，获得王之印记后被大黄蜂救出。离开深渊时会引导小骑士寻找破局之法，杀死赫拉解开封印时会在墓室内哀悼自己的母亲并劝勉小骑士继续前行。最终在黑卵圣殿内，大黄蜂在战斗结尾不顾自己半凡虫的身躯前来控制住前辈，让小骑士得以有机会进入前辈的梦境打败辐光，消除瘟疫本源，不再有梦，摆脱了容器称为空洞骑士的结局。

游戏攻击方式有骨钉挥砍，旋风斩、冲刺斩、强力斩三种剑技（由于手柄默认键位我从未用过），白 / 黑波、白 / 黑吼和白 / 黑砸三种法术攻击，骨钉劈砍的打击感强，而三种法术除了高伤害外各有特点，黑波可以远程穿透攻击，黑吼对上方敌人特攻且可以根据方向排斥或吸引敌人，黑砸有超长的无敌帧。丰富多彩的护符搭配出的不同攻击方式，我常用的为骄傲印记 + 快速劈砍 + 坚固力量的经典莽夫套，也使用了乌恩之形 + 深度聚集 + 快速聚集 + 幼虫之歌的乌恩流派化身为蛆爬过了圣巢万神殿，在流程中打叛徒领主和守望者骑士团也使用过吸虫之巢+萨满之石的吸虫打法，其他流派还包括法术流、召唤流、亡怒流等等，战斗手感强，BOSS 动作模组丰富，既有见招拆招，也可以暴力速通，亦可以逃课苟活，不同的打法能带来不同的感受。

游戏的移动方式包括冲刺以及进化后的黑冲、爬墙、超级冲刺、二段跳、酸泳，其中冲刺和爬墙早期就能获得，且有这俩技能能达成很多破序操作。但是二段跳获得的顺序较后，前期纵向位移能力受限，且游戏不存在预输入指令，导致跳跃操作很容易被吞且二段跳必定有一个下坠，手感并没有很好。游戏的移动方式较为常规，并没有什么特别亮眼的移动方式，游戏最具特色的是下劈操作，下劈刺、下劈怪等操作可以达成很多破序操作，在白宫中，下劈更是必备技能。但是对手柄来说，使用摇杆下劈的下位移判定较窄，容易按成横劈从而失误。

在地图设计上，非常具有类银河城四通八达的特性，从真菌荒地向上经过食腿者处回到十字路、从泪城乘坐大电梯到达十字路、从安息之地经过蓝湖到达萨鲁巴的商店、雾之峡谷通过酸水通道返回十字路，一张张地图通过各种路线连接到十字路，前期迷路的十字路在中期真正成为了四通八达的交通枢纽。另一张四通八达的地图则是泪水之城，前期左半的平民区和中期右半的富人区打通后，圣巢首都是连接圣巢上下各部分区域的核心之地。除了四通八达的连接外，各地图的连接也存在各种破序玩法，比如速通必备的劈魂上蓝湖、酸冲进雾谷、劈刺拿酸泪等等，既可以满足正常的通关流程，也可以给破序玩家应有的爽感。此外，空洞骑士的地图存在数量及其庞大的隐藏，大部分隐藏都是藏在假墙壁之后，需要打碎墙壁进入获得，因此养成了到处敲敲打打的风格。王国边境正是藏在了国王驿站下方的隐藏通道中，蜂巢更是藏在电车到达的王国边境下部的隐藏墙后，需要玩家细心探索（虽然我是看攻略的）。但是，地图设计的庞大并没有与之匹配的便捷的传送机制，游戏的地图传送靠全图共 12 个鹿角虫车站进行，许多地图甚至没有车站（水晶山峰、王国边境），且游戏地图很少有水平笔直的道路，超冲也很少能省下多少跑图时间，拖长了跑图时间。

游戏采用了部分魂系游戏的设定，非钢魂模式下，死亡会失去所有的吉欧，还会失去部分灵魂上限，需要到死亡附近找到移动的魂并将其打死才能收回所有的吉欧和失去的灵魂上限，部分关卡的高压设计（如螳螂村、结晶山丘、深巢中右部分、王后花园）极易容易在找魂途中二次死亡从而失去所有的吉欧，虽然有腐臭蛋可以到德特茅斯右侧找到吉吉找回魂，但是受限于空洞骑士匮乏的传送方式，很多时候回到德特茅斯并不方便，且除了地图上的腐臭蛋外，多的腐臭蛋需要到皇家水道粪虫防御者战上方找图克购买，不够方便。地图庞大且有魂系的死亡惩罚的情况下，游戏的存档点数量较少，特别是前期的螳螂村跑图、中期的水晶山峰跑图和后期的深巢跑图，给游戏增添很多不必要的受苦过程。

Hollow Knight: Silksong（空洞骑士：丝之歌）

作为 Team Cherry 七年磨一剑的大作，丝之歌在前作的基础上，同时放大了优点和缺点。但是，仍不失为一部佳作，仍想直呼“我真幸运！”

以大黄蜂被押送自石桥摔落至苔穴为始，拉开了游戏的第一幕：纺络。穿越绿意盎然的苔穴，到达骸底镇，在教堂侍女的对话中，大黄蜂确定了自己的目标为至高宏伟的圣堡。经过荒芜的髓骨洞窟，炽热的深坞，植被与岩浆交杂的原野，雾蒙迷暗、鸦虫环绕的灰沼，到达钟心镇，昔日温暖的小镇如今众居民却被丝咒控制，通过奇诡的壳木林，来到钟心镇上层，与黑寡妇决战拯救小镇。随后，大黄蜂穿过黄沙漫天的风蚀长阶，来到了圣堡大门前，敲响大门，击败末代裁决者后，大黄蜂踏入圣堡，游戏进入第二幕：圣歌城堡。

进入巨扉圣门，大黄蜂解开天平谜题，进入圣咏殿。爬上始源钟殿，穿过走廊，和机枢舞者完成最后一舞后，唤醒三座雕像。探索低语书库，习得管理员的旋律；爬上机枢核心，习得建筑师的旋律；穿过曲水静流的高庭，习得指挥家的旋律。在白愈厅中发现丝咒背后骇人的真相，在忆廊中揭开圣堡对纺络生态的累累罪行。大黄蜂再次来到三座雕像前，奏响三重旋律，登上电梯，来到摇篮圣所，再次击败蕾丝，收集三个灵魂和陷阱设置器后，看守者协助大黄蜂布置陷阱，迎战纺络丝咒源头：丝母。战斗尾声，大黄蜂奏响旋律启动陷阱，丝母被虚空困住，并困住了大黄蜂，蕾丝斩下丝母手臂救下大黄蜂，而纺络也陷入了虚空的控制之中。游戏进入第三幕：深渊。

大黄蜂通过坍塌的机枢核心上层，回到圣歌盟地。大黄蜂进入深渊，一路向下，在深渊深处见到了蕾丝的虚影。逃离追逐的岩浆，大黄蜂回到了深坞。将情况告知蜗牛萨满，大黄蜂习得深邃挽歌，在珊瑚尖塔击败壳王卡汗，在壳木林圣所击败花王尼莱斯，在远野深处击败斯卡尔歌后卡梅莉塔，在灰沼右侧失落翠庭击败三叶草舞者。收集四颗古之心后，蜗牛萨满施法让大黄蜂进入记忆深处，从白后手中取得永绽花。重回深渊，潜入虚空之海深处，对战失心蕾丝。击败失心蕾丝后，丝母用最后的力量给予大黄蜂灵丝，然而灵丝升腾被层层阻挡的虚空触手阻挡，永绽花亦失去光芒。最终，虚空神小骑士前来斩断触手，将大黄蜂和蕾丝送回深渊地面，纺络的枷锁自此斩落。

与前作最明显的区别在于，小骑士是容器，没有为苦难哭泣的声音，无法说话，只能倾听他虫的描述；而大黄蜂是半神生物，能够交流，这为本作增加了非常丰富的关于主角的刻画。从骸底镇到钟心镇再到圣歌盟地，大黄蜂不断帮助三个营地的居民完成祈愿，和不同的居民交流获得信息，不仅游戏剧情的推进更清晰，且更加塑造了一个温柔果敢、坚强刚硬、沉着镇定的大黄蜂的鲜活形象。圣巢衰落后，大黄蜂守护圣巢多年，直至小骑士到来击败辐光；被抓到纺络后，大黄蜂仍然肩负拯救世界的使命，纵然纺络并不是大黄蜂的故乡，一路上，大黄蜂面对地图姐沙克拉、老爷子加盟德、小朝圣者谢尔玛都体现了温柔与尊重，面对不礼貌的行为大黄蜂也敢于出手，最后也为了拯救纺络毅然登上摇篮圣所，深入深渊之底，即使明知自己可能再也回不来也从未害怕，在深渊之底，面对失心蕾丝的嘲讽，大黄蜂毅然说出“我熬过无数荆棘，也见证过无数奇迹，但我永远是圣巢之女，对万物之底的虚空，再无畏惧！”并跳下虚空之海，进行最终决战。事实上，如果小骑士没有出手，大黄蜂的确和失心蕾丝同沉与深渊之海了，大黄蜂的确是做好了牺牲的准备。大黄蜂的坚强温柔底色，来自于身为三后之女、圣巢公主的经历。赤红忆境中，生母赫拉告诫女儿“不要听他们的絮语，伟大、崇高、编织者、守护者、女王，皆为她们所欲，而非你所求，更非我所愿，唯有抵抗，方见一线生机”，生母教会大黄蜂追寻自由、追寻自己的人生；师傅蜂后维斯帕教会大黄蜂精湛的战斗技艺，并教导大黄蜂保护自己，守护本心；养母白色夫人将大黄蜂当亲生女儿一样抚养，给予赫拉沉睡而无法给予的关照，并以圣巢之后的身份教会大黄蜂责任和使命。忆境结尾，封印中的白后亲临忆境，“你一定历经了不可估量之痛，才得此彻悟”，鼓励、关爱大黄蜂并亲自将永绽花交给了坚定决心力量的大黄蜂。

在攻击方式上，大大丰富了前作的战斗系统。本作共有七种不同的纹章，每种纹章都有不同的攻击模组，每个纹章都有独有的上劈、下劈、蓄力斩和冲刺斩，灵活运用不同的斩击方式实现帅气的连招。每个纹章也有不同的纹章槽数和不同的纹章技能，匹配不同的战斗风格。猎手的专注叠加，漫游者的快攻莽夫，收割者的见招拆招，野兽的疯狗撕咬，建筑师的道具作战，女巫的吸血与环取，萨满的法术轰炸，不同的纹章带来截然不同的战斗体验。

工具方面，本作共有 41 种红色工具，这些工具功能各异，有增益药水如蓝血火刀，有陷阱道具如蛰刺地刺，有范围群攻如三重镖，有多判如曲镰螺切刃，还有些用处不大但是很帅的，点名丝弹，自己修的真的超帅的。打不同的小怪、不同的连战和不同的 BOSS，选择正确的工具可以事倍功半，轻松取胜。此外蓝色工具还有许多战斗增益，如多重缚丝器和注丝套针专注回血，速射索花心囊加成工具，锯齿环、迅捷脊索改变移动方式等等，好用的道具常常不够槽位装备，可玩性特别高。常用的组合有：漫游者 + 多重缚丝器 + 注丝套针 + 德鲁伊双瞳的莽夫换血流，建筑师 + 蓝血 + 另外两种工具 + 德鲁伊双瞳的苟活道具流，女巫 + 锯齿环 + 双重爪镜的绚丽战斗流等等，纹章与工具的组合五花八门，各有胜场。

本作同样有多种法术，共有六种法术，丝之矛前方穿透灌伤，灵丝风暴360度高伤且兼具格挡投掷物的效果，丝刃冲刺横向位移加无敌帧，十字绣弹反，符文之怒大范围爆伤，苍白之爪全自动跟踪，除建筑师不能携带法术、萨满可以携带三种法术外，其余的纹章均只能携带一种法术，需要在不同法术之间做权衡选择。虽然我全程是带着灵丝风暴的，范围广，伤害高，还能格挡投掷，超模攻击。

游戏的移动方式包括：冲刺与疾跑、漂浮、爬墙、飞针、二段跳、超级跳，与前作相同，二段跳获取时间较为靠后，前期纵向位移能力受限。此外，由于漂浮和跳跃共用跳跃键，导致漂浮必须先二段，而由于不存在预输入二段跳必然有下坠和上移，操作手感不太友好。和前作对比，本作空中能力大幅增强，除了二段跳外，漂浮和飞针给了大黄蜂极强的空中灵活度，既可以缓降、也可以大幅度的横向位移，再搭配冲刺和工具滞空，大黄蜂有着超级优秀的空战能力。而本作跳跳乐难度甚至不到前作的白色宫殿，实际上完全没有发挥出大黄蜂的空中能力上限。本作不太友好的地方在于第三张图才拿到第一个位移能力冲刺，第四张图拿到漂浮，第六张图拿到爬墙，第一幕的位移能力给的太过拘束导致前期行动能力不佳，和怪的拉扯不舒适。而第二幕获得飞针后又变成了爽游，除了一些极限的地方，飞针想怎么走就怎么走，有了非常丰富的位移自由度。
